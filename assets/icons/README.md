# Stack icons

Vendored from [Devicon](https://github.com/devicons/devicon) at commit
`6a37858047b0e8d9c9c0e68f4a071fc410652e89`, except the blue hexagonal C logo,
which comes from the [v2.16.0 release](https://github.com/devicons/devicon/blob/v2.16.0/icons/c/c-original.svg). The upstream MIT license is included in `LICENSE`.
Logos belong to their respective owners and are used to identify technologies.

The generator embeds these SVGs directly, so badges require no remote image requests.
React Native shares the React logo. AI tool icons come from
[Lobe Icons](https://github.com/lobehub/lobe-icons/tree/8a1b2821bb768c484fe8da20c5e1838b6bf551a9)
at commit `8a1b2821bb768c484fe8da20c5e1838b6bf551a9`; its MIT license is
included in `LICENSE-lobe-icons`. Claude Code uses the Claude logo, and Codex
uses the OpenAI logo. All icons are embedded locally, including the AI tools.
